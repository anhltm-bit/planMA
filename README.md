# planMA — BA Planner

Phần mềm sắp xếp và lên kế hoạch công việc cho Business Analyst (HTML/CSS/JS thuần, không cần cài đặt).

- **Phân tích**: Ma trận 4 ô (Eisenhower) với gợi ý tự động theo tri thức BA · Phân tích 80/20 (Pareto)
- **Kế hoạch**: tự lập theo Ngày / Tuần / Tháng / Năm / Khoảng tùy chọn · kho việc ghim/đóng mở · việc định kỳ
- **Báo cáo**: dashboard thời gian theo ô ma trận, loại việc BA, đúng hạn, việc dồn lại · xuất CSV

## Chạy
Mở `index.html` trực tiếp bằng trình duyệt (dữ liệu lưu trong localStorage). Có thể xuất/nhập dữ liệu JSON ở menu trái.
